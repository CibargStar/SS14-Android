# Установка и тестирование на телефоне

## Требования

Android 8.0 / API 26 или новее, ARM64. Для x86-64 есть отдельный тестовый APK. Нужны свободное место для движков и контента сервера и доступ в интернет. Объём контента зависит от сервера и может значительно превышать размер APK.

Совместимость с устройствами, использующими страницы памяти 16 КБ, пока не подтверждена: остаётся ограничение native SkiaSharp. См. [совместимость](compatibility.md).

## Установка

1. Откройте [GitHub Releases](https://github.com/CibargStar/SS14-Android/releases?q=android-host&expanded=true), выберите последний `android-host-*`.
2. Для Samsung S25 Ultra скачайте `SS14-Android-…-arm64-coreclr.apk`.
3. Разрешите установку приложений из выбранного браузера/файлового менеджера и установите APK. Новый релиз устанавливается поверх предыдущего с той же подписью.
4. Откройте Space Station 14, войдите в аккаунт и выберите сервер из хаба либо укажите его адрес.
5. Дождитесь загрузки движка и контента. Отдельный архив игры и локальный сервер не нужны.

Если нужная версия движка ещё не портирована, подключение завершится ошибкой. Выбор другого бинарника с похожим номером не обеспечит совместимость. В отчёте укажите сервер и запрошенную версию.

## Управление

Стик отвечает за движение. Он удерживает один палец, поддерживает восемь направлений и освобождает движение при потере фокуса. Размер сенсорного управления и масштаб игровых окон настраиваются отдельно: раздел «Экран и управление в игре» в лаунчере или кнопка `UI` в игре. Там же можно скрыть сенсорные кнопки; кнопка `UI` остаётся для их восстановления.

В версии 0.6.1 и новее:

- Поставьте два пальца на свободное игровое поле, вне окон, HUD и кнопок.
- Разводите пальцы для приближения, сводите — для возврата. Диапазон: от обычного серверного вида до увеличения в 4 раза.
- Поворачивайте пальцы вокруг друг друга для вращения камеры.
- После поворота стик продолжает двигать персонажа в направлении, показанном на экране.

Жест не расширяет область видимости, разрешённую сервером. Первый палец не должен заранее начать перетаскивание или удержание: после этого он принадлежит обычному игровому действию. Жесты работают и при скрытых сенсорных кнопках.

Игра запускается с убранными системными панелями. Android может временно показать их после свайпа от края; после возврата фокуса полноэкранный режим восстанавливается. Экранная клавиатура работает отдельно.

## Что проверить в новом билде

1. Войти через хаб на привычный сервер, загрузить карту.
2. Приблизить и повернуть камеру, выбрать предмет на карте после поворота.
3. Одновременно двигаться стиком и менять камеру двумя другими пальцами.
4. Проверить одиночное нажатие, удержание, перетаскивание и работу окон: жесты не должны нажимать предметы или кнопки.
5. Скрыть управление, повторить жесты; вернуть кнопки через `UI`.
6. Свернуть приложение, вернуться, открыть/закрыть клавиатуру. Проверить отсутствие застрявшего движения и восстановление полного экрана.

## Отчёт об ошибке

Создайте [issue](https://github.com/CibargStar/SS14-Android/issues/new/choose): модель телефона, версия Android, версия APK, сервер, версия движка, шаги и лог. Логи доступны через штатную функцию открытия папки логов в лаунчере. Для сбоя Android полезен `adb logcat` во время воспроизведения. Удалите из прикладываемых файлов токены, личные данные и адреса частных серверов.
