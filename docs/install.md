# Установка и тестирование на телефоне

## Требования

Android 8.0 / API 26 или новее, ARM64. Для x86-64 есть отдельный тестовый APK. Нужны свободное место для движков и контента сервера и доступ в интернет. Объём контента зависит от сервера и может значительно превышать размер APK.

Совместимость с устройствами, использующими страницы памяти 16 КБ, пока не подтверждена: остаётся ограничение native SkiaSharp. См. [совместимость](compatibility.md).

## Установка

1. Откройте [GitHub Releases](https://github.com/CibargStar/SS14-Android/releases?q=android-host&expanded=true), выберите последний `android-host-*`.
2. Для Samsung S25 Ultra скачайте `SS14-Android-…-arm64-coreclr.apk`.
3. Разрешите установку приложений из выбранного браузера/файлового менеджера и установите APK. Новый релиз устанавливается поверх предыдущего с той же подписью.
4. Откройте Space Station 14, войдите в аккаунт и выберите сервер из хаба либо укажите его адрес.
5. Дождитесь загрузки движка и контента. Отдельный архив игры и локальный сервер не нужны.

Если нужная версия движка ещё не портирована, подключение завершится ошибкой. Выбор другого бинарника с похожим номером не обеспечит совместимость. В отчёте укажите сервер и запрошенную версию.

## Управление

В 0.8.0 накладное управление содержит только стик и кнопку `UI`. Дополнительные кнопки действий, ESC, клавиатуры и редактора удалены. Стик поддерживает восемь направлений и прекращает движение при отпускании/потере фокуса. Масштаб и скрытие стика доступны через `UI` или раздел «Экран и управление в игре» в лаунчере.

В настройках лаунчера есть галочка **«Мобильный чат и панель меню»**. Включённая галочка заменяет компоновку серверного чата и меню мобильной; отключённая сохраняет исходный серверный UI. Изменение применяется при следующем запуске игры. [Управление чатом и границы адаптации](mobile-ui.md).

В версии 0.6.1 и новее:

- Поставьте два пальца на свободное игровое поле, вне окон, HUD и кнопок.
- Разводите пальцы для приближения, сводите — для возврата. Диапазон: от обычного серверного вида до увеличения в 4 раза.
- Поворачивайте пальцы вокруг друг друга для вращения камеры.
- После поворота стик продолжает двигать персонажа в направлении, показанном на экране.

Жест не расширяет область видимости, разрешённую сервером. Первый палец не должен заранее начать перетаскивание или удержание: после этого он принадлежит обычному игровому действию. Жесты работают и при скрытом стике.

Начиная с APK 0.7.0, отпускание и отмена касания дополнительно проверяются по активным пальцам Android. Стик возвращается в центр и отпускает движение даже при потере события SDL. Лаунчер равномерно вписывает исходное окно в доступную область экрана; прокрутка остаётся внутри списка серверов.

## Панель Debug

Откройте `UI` → `Debug`. Повторное нажатие или крестик закрывает панель. Она показывает FPS, среднее время кадра, CPU игрового процесса, память игры (PSS), управляемую память .NET и свободную/общую RAM устройства. CPU нормализован по числу доступных ядер: загрузка одного ядра из восьми соответствует примерно 12,5%.

PSS включает долю общих страниц и native-память; .NET — отдельный показатель управляемых объектов, его не нужно прибавлять к PSS. Метрики относятся к игровому процессу, лаунчер работает отдельно. Данные обновляются раз в секунду только при открытой панели. Полные Android-метрики требуют APK 0.7.0 или новее.

Игра запускается с убранными системными панелями. Android может временно показать их после свайпа от края; после возврата фокуса полноэкранный режим восстанавливается. Экранная клавиатура работает отдельно.

## Что проверить в новом билде

1. Проверить хаб: логотип, заголовок, поиск и нижние вкладки полностью видны; прокручивается только список серверов.
2. Войти на привычный сервер и загрузить карту. Отклонить стик, отпустить: ручка возвращается в центр, персонаж останавливается. Повторить при удержании второго пальца на другом участке экрана.
3. Открыть `UI` → `Debug`, подождать 2–3 секунды. Проверить обновление FPS, CPU и памяти; закрыть крестиком и открыть снова.
4. Приблизить и повернуть камеру двумя пальцами вне интерфейса, выбрать предмет после поворота; проверить движение стиком одновременно с жестом.
5. Проверить три режима чата: скрытый (только кнопка), минимальный, полный. Во всех режимах чат прижат к правому верхнему краю. Проверить первое касание/удержание кнопок, отсутствие подсказок и двойного переключения; центрирование иконок меню. Затем проверить прокрутку, каналы, фильтры, отправку и клавиатуру.
6. Выключить мобильный UI в лаунчере, перезапустить игру и проверить исходный чат/меню сервера. Снова включить и перезапустить. Свернуть приложение во время движения и вернуться. Персонаж должен остановиться; полноэкранный режим должен восстановиться. Проверить открытие/закрытие клавиатуры.

## Отчёт об ошибке

Создайте [issue](https://github.com/CibargStar/SS14-Android/issues/new/choose): модель телефона, версия Android, версия APK, сервер, версия движка, шаги и лог. Логи доступны через штатную функцию открытия папки логов в лаунчере. Для сбоя Android полезен `adb logcat` во время воспроизведения. Удалите из прикладываемых файлов токены, личные данные и адреса частных серверов.
