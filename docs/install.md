# Установка и управление

Требования: Android 8 / API 26+, ARM64 или x86-64, интернет и свободное место под движки и контент. Объём зависит от сервера. [Ограничения платформы](compatibility.md).

## Установка

1. Откройте [Releases](https://github.com/CibargStar/SS14-Android/releases?q=android-host&expanded=true) и выберите последний `android-host-*`.
2. Скачайте `arm64-coreclr.apk` для ARM64 или `x64-coreclr.apk` для x86-64.
3. Разрешите установку из браузера/файлового менеджера и установите APK. Релиз с прежней подписью устанавливается поверх предыдущего.
4. Откройте Space Station 14, войдите в аккаунт, выберите сервер из хаба или укажите адрес.
5. Дождитесь загрузки движка и контента. Отдельный архив игры и локальный сервер не нужны.

Если версия движка ещё не портирована, укажите сервер и запрошенную версию в [issue](https://github.com/CibargStar/SS14-Android/issues/new/choose).

## Управление

- **Стик:** восемь направлений; при отпускании или потере фокуса движение прекращается. Через **UI** можно изменить масштаб и скрыть стик.
- **Камера:** два пальца на свободном игровом поле — щипок для увеличения в 1–4 раза, поворот для вращения. Стик учитывает поворот, выбор предметов — положение камеры. Серверная область видимости сохраняется.
- **Чат и меню:** галочка **«Мобильный чат и панель меню»** в лаунчере включает [мобильную компоновку](mobile-ui.md). Выключение возвращает исходный UI сервера при следующем запуске игры.
- **Полный экран:** системные панели скрыты; после свайпа от края Android может временно показать их.

Жест камеры начинается вне окон, HUD и кнопок, пока первый палец не начал игровое удержание или перетаскивание. Скрытие стика не отключает жесты. Масштаб интерфейса также доступен в разделе лаунчера «Экран и управление в игре».

## Debug

Откройте **UI → Debug**. Панель показывает FPS, среднее время кадра, CPU игрового процесса, память процесса (PSS), управляемую память .NET и свободную/общую RAM. Обновляется раз в секунду только пока открыта.

CPU нормализован по числу ядер: одно занятое ядро из восьми — около 12,5%. Память .NET входит в память процесса; прибавлять её к PSS не нужно. Лаунчер работает отдельным процессом.

## Проверка нового релиза

1. Хаб целиком помещается в экран; прокручивается список серверов, а не всё окно.
2. Игра загружается. Стик останавливает персонажа при отпускании, в том числе при удержании второго пальца.
3. Debug обновляет показатели, закрывается и открывается повторно.
4. Камера приближается и поворачивается; после поворота работают движение и выбор предметов.
5. Чат переключается между скрытым, минимальным и полным режимами. Меню сворачивается, иконки центрированы, кнопки реагируют с первого касания. Работают история, каналы, фильтры, отправка и клавиатура.
6. После выключения мобильного UI и перезапуска игры возвращается исходная компоновка сервера.
7. При сворачивании во время движения персонаж останавливается; после возврата восстанавливается полный экран. Клавиатура открывается и закрывается.

## Логи

Для [отчёта](https://github.com/CibargStar/SS14-Android/issues/new/choose) нужны версия APK, устройство/Android, сервер, версия движка, шаги и лог. Логи доступны через открытие папки логов в лаунчере; при сбое Android запишите `adb logcat`. Перед публикацией удалите токены, личные данные и адреса частных серверов.
