# Состояние интеграции клиента и хаба

Цель полного порта сохраняется. Следующие результаты — промежуточные компоненты, не заявление о готовом игровом клиенте.

**Реализовано**

- Android-приложение `src/SS14.Android`: официальный хаб и резервный URL, поиск, избранное в приватном хранилище, прямой адрес, запрос сведений о сборке. Встроенных списков разрешённых серверов или форков нет. Сетевые ошибки показываются, данные не заменяются демонстрационными серверами.
- `Launcher.Core`: ss14/ss14s URI, IPv6, порт 1212 по умолчанию для ss14, пути reverse proxy, точная идентичность engine/content/fork, ACZ/client.zip URL, отмена запросов и fallback хаба, атомарное сохранение избранного.
- Официальный RobustToolbox закреплён Git submodule на `160be31f57129c24c1715b873b92f14d028de8b8`. Выделен платформенный патч из 39 файлов: SDL/GLES, переносимость шейдеров, multi-touch events, виртуальные действия, прокрутка и перемещение окон. Патч воспроизводимо применяется скриптом; сборка Robust.Client проходит.
- Сохранены исходные engine/content loader, sandbox, сетевая авторизация, параметры освещения/FOV. В APK не вшивается единственная серверная сборка. Импортированные снижения качества графики исключены, UI сохраняет автоматическое масштабирование. Сенсорные элементы по умолчанию включаются только на Android.
- SDL3 собран из закреплённой upstream-ревизии `f0e99e7c7f9aa90d5ce2e3b8a69f72c23faf257e` через NDK r27c для Android API 26 / ARM64. Формат ELF AArch64 проверен. Подготовлены локальные build scripts и GitHub Actions workflow; workflow удалённо не запускался.
- Также собраны ARM64-библиотеки FreeType 2.13.3, OpenAL Soft 1.24.3 и Zstd 1.5.7. Commit IDs и SHA-256 записаны в `artifacts/native/arm64-v8a/libraries.json`, рядом сохранены лицензии. `scripts/build-native-libraries.sh` закрепляет точные исходные commits. Библиотеки ещё не связаны с игровым процессом; сборка не подтверждает вывод звука или рендеринг шрифтов на устройстве.

**Проверки**

Сетевой контракт хаба, резервный адрес и timeout, отмена, ss14/ss14s/IPv6 и reverse-proxy URL, метаданные серверной сборки, ACZ URL и избранное проверяются в `tests/Launcher.Tests`. Это проверки через подставной HttpMessageHandler; доступность живого хаба ими не подтверждается. В этой среде оба официальных hub endpoint возвращали 403. APK собран, Android-устройство не подключено; UI и игровые действия на устройстве ещё не проверялись.

Сборка upstream-движка выдаёт предупреждения анализаторов и NuGet (в том числе по закреплённой upstream-зависимости ImageSharp). Они не скрыты и записаны в build logs. Сборка не равна готовности к публикации.

**Осталось до игрового подключения**

1. Оставшиеся Android-native зависимости, включая криптографию и MIDI; упаковка и проверка ABI/native loader для всего набора. SDL, OpenAL, FreeType и Zstd собраны, но это ещё не весь набор и не проверка их исполнения.
2. Игровая Activity/JNI и bootstrap отдельного процесса с правильным жизненным циклом SDL/GL. Управляемый движок пока собирается отдельно и не запускается из APK хаба.
3. Подписанные версии Android engine, проверка установки, обновление/восстановление пакетов, загрузка оригинальных DLL и ресурсов серверов через ZIP/ACZ.
4. Аккаунты, штатная авторизация, сохранение токенов, privacy flow и сетевое подключение. Вызов /info не считается входом на сервер.
5. Привязка мобильного ввода к загруженному игровому контенту и проверка всех действий, окон, чата, звука и графики на устройствах. Встроенный веб-контент и остальные платформенные функции остаются обязательствами переноса.
6. Самообновление APK, установка средствами Android, сохранение настроек и ключей, проверка нескольких версий движка/форков.

Получение метаданных в приложении сейчас завершается информацией о сборке и явным сообщением о неподключённом игровом запуске. Это временное состояние разработки, а не финальная функция «подключения».
