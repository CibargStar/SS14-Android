# Совместимость и ограничения

Цель проекта — серверы из официального хаба и прямые подключения без списка разрешённых форков. Для подключения требуется **Android-порт именно запрошенной версии движка**, совместимые native-зависимости и работающий контент сервера.

## Опубликованные версии движка

```text
275.1.5  275.2.5  276.0.4  277.0.4  277.2.3  278.0.2
283.1.5  286.0.2  288.0.3  288.1.2  289.0.5  290.0.2  291.0.2
292.0.1  293.0.1  294.0.0  294.0.1
```

APK содержит 294.0.0 и 294.0.1. Остальные подготовленные версии скачиваются по необходимости. Каталог также сохраняет 42 официальных repair redirect на опубликованные разрешённые цели. Компиляция версии подтверждает сборку, но не прохождение раунда на каждом использующем её сервере.

Обследование хаба: 180 записей, 179 ответов, 41 запрошенная версия, 30 конечных сборок после redirect. Из них портированы 17; остальные 13 требуют работы. Снимок быстро устаревает: [engine-versions-observed.json](engine-versions-observed.json). Текущий каталог — [ветка updates](https://github.com/CibargStar/SS14-Android/blob/updates/engines.json).

Для запросов **286.0.0 и 286.0.1** действует официальный redirect на разрешённую **286.0.2**. Старые бинарники этих двух версий отозваны upstream и не публикуются. APK менять не требуется: версия 286.0.2 загружается из каталога.

## Устройства и runtime

- Минимальная платформа сборки — Android 8 / API 26.
- ARM64 — основной вариант; Samsung S25 Ultra: пользователь подтвердил загрузку игры из хаба.
- x86-64 — отдельная тестовая сборка для совместимых устройств/эмуляторов.
- Публикуемый runtime — экспериментальный CoreCLR .NET 10; Mono используется для сравнения и диагностики.
- Проверки нового кода на Linux offscreen не заменяют запуск соответствующего APK на физическом устройстве.

## Открытые ограничения

| Область | Состояние |
| --- | --- |
| Полный игровой цикл | Нет записанного сквозного теста полного раунда со всеми действиями |
| Все серверы | Не все запрашиваемые версии движка портированы; все форки не проверены |
| Native-функции | MIDI и замена CEF/WebView для Android ещё требуют реализации |
| Lifecycle и ввод | Нужна проверка на устройствах: IME, сворачивание, системные диалоги, внешняя мышь/клавиатура |
| Обновление APK | Проверки установщика есть; полный цикл через системный установщик требует проверки на телефоне |
| Страницы 16 КБ | SkiaSharp 2.88.9 имеет ELF-выравнивание 4 КБ; zipalign этого не исправляет |
| ImageSharp | В upstream-зависимости 3.1.12 остаётся GHSA-v76p-62qx-wwq2 при обработке TIFF. Обновление на 3.2.0 остановлено требованием лицензионного ключа; NuGet audit не отключён |

Проект выпускает тестовые prerelease. Готовность универсального стабильного клиента пока не заявляется.
