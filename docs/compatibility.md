# Совместимость

Цель — серверы официального хаба и прямые подключения без списка разрешённых форков. Для подключения нужны Android-сборка запрошенной версии движка, совместимые native-зависимости и работающий контент сервера.

В частности, запросы **286.0.0 и 286.0.1 → 286.0.2**: отозванные бинарники не публикуются, обновлять APK для этой загрузки не требуется.

[Снимок хаба от 28 октября 2026](engine-versions-observed.json): 180 записей, 179 ответов, 41 запрошенная версия и 30 конечных версий после redirect. Портированы 17, остаются 13. Снимок не отражает последующие изменения серверов; сборка движка не подтверждает игровой раунд на всех форках.

## Платформа

Android 8 / API 26 и новее. Основная архитектура — ARM64, отдельная тестовая — x86-64. Публикуемый runtime — экспериментальный CoreCLR .NET 10; Mono оставлен для диагностики.

## Открытые ограничения

| Область | Состояние |
| --- | --- |
| Игровой цикл | Полный раунд и все форки ещё не проверены |
| Native-функции | MIDI и замена CEF/WebView требуют реализации |
| Android lifecycle и ввод | Нужны проверки IME, сворачивания, системных диалогов, низкой памяти, внешней мыши/клавиатуры |
| Обновление APK | Полный цикл через системный установщик ещё требует проверки на телефоне |
| Страницы 16 КБ | SkiaSharp 2.88.9 имеет ELF-выравнивание 4 КБ; `zipalign` этого не исправляет |
| ImageSharp 3.1.12 | Не закрыта [GHSA-v76p-62qx-wwq2](https://github.com/advisories/GHSA-v76p-62qx-wwq2) при обработке TIFF. Переход на 3.2.0 требует лицензионного ключа; NuGet audit включён |
| Подпись APK | Используется постоянный development-сертификат; переход на другой потребует плана миграции |

Среды и границы выполненных проверок: [current-validation.md](current-validation.md).
