## Что покрывает стенд

- Ввод проходит через `SDL_PushEvent → Clyde → GameController → UI/InputManager`. Проверяются отпускание стика, потерянный SDL_UP при втором удерживаемом пальце, повторное использование pointer ID и отмена. Android MotionEvent проверен компиляцией host и pointer-тестами; список физических пальцев в Linux подставляет fixture.
- HUD проверяется на исходном `DefaultGameScreen`: три режима чата, примыкание к углу, центры иконок, касание/удержание без подсказки и двойного переключения, история, черновик, widget lookup, ancestor handler и восстановление UI. Submit использует пробельную строку без сетевой отправки.
- Debug открывается SDL-нажатием и получает FPS/CPU/память после интервала измерения; после закрытия сбор метрик прекращается. Linux использует RSS. Android PSS, системную RAM, живые сообщения, IME и popup ещё нужно проверить на устройстве.
- Предыдущий Android-эмулятор загружал главное меню, 3200 RSI, 918 текстур и проходил transport/serializer handshake с внутренним сервером 294.0.1. Это не проверка полного раунда или нового APK.
