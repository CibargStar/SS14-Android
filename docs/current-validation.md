## Покрытие и границы

- Ввод проходит через `SDL_PushEvent → Clyde → GameController → UI/InputManager`. Проверены отпускание стика, потерянный SDL_UP, второй палец, повторное использование pointer ID и отмена. Android MotionEvent покрыт компиляцией host и pointer-тестами; Linux использует снимок пальцев из fixture.
- HUD: три режима чата, порядок кнопок, привязка к углу, иконки, касание/удержание, история, черновик и восстановление UI. Submit проверяется пробельной строкой без отправки сообщения в сеть.
- Лобби и гайд: исходные панели, границы окна/закрытия, узкая компоновка, оглавление, прокрутка, вкладки персонажей и восстановление родителей/порядка действий. Повторное обновление адаптера сохраняет валидную компоновку гайда. В редактор загружается исходный HumanoidCharacterProfile через SetProfile: проверены живой preview entity после перепривязки, поворот исходной кнопкой, native popup разделов, ширина полей и цветов при автоматическом и ручном масштабе. Стенд использует локальные данные; серверное сохранение предпочтений и действия в раунде требуют проверки в игре.
- Debug получает FPS/CPU/память и прекращает опрос после закрытия. Linux использует RSS; Android PSS, системную RAM, IME, живые сообщения и popup нужно проверить на устройстве.
- Предыдущий Android-эмулятор загружал главное меню, 3200 RSI, 918 текстур и проходил transport/serializer handshake с внутренним сервером 294.0.1. Полный раунд и все форки ещё не проверены.

Hash сериализации исходного контента: `8E31801C357F2F7DB888F10EDC878803DAA3CD678D7E5DBA912584BDCD3C9AEC`.
