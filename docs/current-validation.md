# Подтверждённые результаты

Версия 0.8.1-dev, 29 октября 2026. Результаты относятся к указанным стендам; сборка движка не подтверждает совместимость каждого сервера.

| Среда | Подтверждение |
| --- | --- |
| Pure .NET | 72 проверки оригинального лаунчера, 7 Android pointer, 70 масштаба/настроек, 36 стика, 28 жестов камеры |
| Оригинальный хаб, Avalonia headless/Skia | Авторизованная fixture с 180 локальными серверами: окно и навигация вписываются в 600×260, 780×360, 1040×480, 960×540; внешний скролл отсутствует |
| Linux offscreen, окончательный подписанный 294.0.1 | 9 проверок native SDL input, 9 камеры, 8 стика, 36 мобильного HUD, 2 Debug; оригинальные Content.Client/Shared/Shared.Database, UI и sandbox |
| Бинарная дельта 294.0.0 | 11 проверок: точные итоговые байты, неверный источник/версия, повреждения, лимиты и отмена |
| Android CI | CoreCLR ARM64/x64, 16 точных движков; подписи, ABI, version code 10, сертификат, ключ движков и оригинальная иконка проверены |
| Samsung S25 Ultra | Пользователь ранее подтвердил вход из хаба в игру. Новый APK 0.8.1 на устройстве ещё не проверен |

Input-стенд отправляет реальные SDL_PushEvent через штатную цепочку Clyde → GameController → UI/InputManager. Он проверяет возврат стика в центр, потерянный SDL_UP при другом удерживаемом пальце, повторное использование pointer ID и отмену. Список физических пальцев подставляется fixture; получение Android MotionEvent проверено сборкой host и отдельными pointer-тестами, на физическом телефоне ещё предстоит проверка.

Debug открывается настоящим SDL-нажатием через UI → Debug; после интервала измерения проверяются FPS, время кадра, CPU и память процесса. На Linux используется RSS, на Android предусмотрен PSS через Android.OS.Debug. Показатели Android CPU/PSS и системной RAM на телефоне пока не подтверждены. Панель не вызывает сбор метрик после закрытия.

Сериализация оригинального контента сохранила hash `8E31801C357F2F7DB888F10EDC878803DAA3CD678D7E5DBA912584BDCD3C9AEC`.

Исходники host и движков: `cd0d50761a0f8a73deab3481242cf6ea3d611bdb`. [Матрица 16 движков](https://github.com/CibargStar/SS14-Android/actions/runs/40863285521), [host ARM64](https://github.com/CibargStar/SS14-Android/actions/runs/40863290098), [host x64](https://github.com/CibargStar/SS14-Android/actions/runs/40863294596).

HUD-стенд использует настоящий DefaultGameScreen. Дополнительно проверены три режима, примыкание к верхнему/правому краю с точностью до пикселя, центры иконок, скрытие до единственной кнопки, восстановление полного режима, действие на finger-down и отсутствие Tooltip/двойного переключения после удержания через несколько кадров. Проверяет оригинальные ChatBox/MenuButton, widget registry, сохранение ancestor handler ссылок, сворачивание меню/чата, черновик, увеличенную историю, прокрутку без клика, один обычный tap, штатный submit и полное восстановление исходной компоновки при отключении/выгрузке экрана. Submit проверяется пробельной строкой без сетевой отправки. На телефоне ещё предстоят проверка живых сообщений, popup каналов/фильтров и экранной клавиатуры.

В обоих окончательных APK все 649 записей вне engine assets и файлов подписи побайтно совпадают с соответствующим CI APK. Встроены только 294.0.0 и 294.0.1; канал содержит 16 точных версий и 40 официальных redirect. APK подписаны прежним сертификатом, пакеты движков — постоянным Ed25519-ключом.

Предыдущие проверки Android-эмулятора подтверждали исходное главное меню, 3200 RSI, 918 текстур и transport/serializer handshake с внутренним сервером 294.0.1. Они не заменяют запуск нового APK и полный игровой раунд.
