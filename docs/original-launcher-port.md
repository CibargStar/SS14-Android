# Порт оригинального SS14.Launcher

Требование пользователя: адаптировать существующее приложение и сохранить его функции; не создавать похожий интерфейс с нуля. Самописный хаб 0.1.0-dev выведен из основного проекта и оставлен в experiments.

Официальный upstream: https://github.com/space-wizards/SS14.Launcher, commit 18fa9830576023595bffb417b0eaeb929fee5934. В основной APK включается сборка SS14.Launcher с его XAML, ресурсами, моделями, авторизацией, ServerListCache, ContentManager, Updater и EngineManagerDynamic. ProjectReference на бывший Launcher.Core удалён.

Платформенный патч меняет desktop entry point на Avalonia.Android lifetime, адреса файлов, вызов браузера/ss14 intents и представление четырёх Window в единственном Android TopLevel. Основное содержимое MainWindowContent.xaml и XAML вкладок/логина не переписано. Адаптер сохраняет типы исходных диалогов, их обработчики, результаты, отмену и блокировку владельца. Desktop-вариант PlatformWindow остаётся Window. Нативный выбор файлов использует Avalonia StorageProvider.

Для совместимости с Android обновлены Avalonia до 11.3.22 и SQLitePCLRaw bundle до 2.1.14. Ручное объявление исходных .xaml обновлено под генератор Avalonia; разметка экранов остаётся исходной. Desktop-only зависимости исключены из мобильной упаковки, не из исходного desktop-приложения. Unix chmod реализован через .NET API на Android. libsodium собран из официального релиза 1.0.20 через NDK с проверкой SHA-256 архива и 16-КБ выравниванием; версия для glibc не должна попадать в APK. Zstd использует Android build и специальный native resolver. Штатные подписи движков и проверка контента не отключаются.

Таблица RID исправлена: Android не проходит по историческим fallback-рёбрам к linux-arm64. Указание совпадающего процессора не делает glibc-библиотеку совместимой с Android/Bionic. Отсутствие Android-версии движка должно завершаться ошибкой, а не скачиванием desktop engine. Собственный подписанный каталог и запуск Android engine ещё не интегрированы.

Проверено на headless/Skia стенде: загрузка оригинальной разметки и ViewModels, оригинальные миграции SQLite, сохранение избранного, исходные диалоги подключения/избранного/настроек хабов, вложенная модальность и отмена, системные ссылки, RID. HTTP в тесте заменён на ответ 503; реальные аккаунты, хаб и серверы не используются. Скриншот artifacts/original-launcher-login.png получен из рендера исходного интерфейса в этой среде, не с Android-устройства.

Открытые задачи:

- Запуск и испытание на реальном Android: login/registration/2FA, списки хаба, фильтры, новости, настройки, file picker, смена языка, жизненный цикл, IME и accessibility. Исходный код присутствует; полная работоспособность ещё не подтверждена.
- Игровая Activity/JNI, все native зависимости (включая MIDI), управляемый engine loader, сохранение штатного sandbox и согласование клиентского контента.
- Публикация и установка подписанных Android engine, ACZ/client.zip, проверка обновления/обрыва/отката и нескольких форков. Штатный Updater включён, но Android catalog и запуск игры ещё не готовы.
- Экспорт журналов адаптирован: обе исходные команды открытия каталога вызывают Android share sheet с ZIP через FileProvider; доступ выдаётся только к cache/exports. Маршрутизация покрыта тестом, сам Android share sheet ещё требует испытания на устройстве.
- Полная адаптация размеров исходного интерфейса под телефоны, проверка касаний и экранной клавиатуры. Текущий host запускает landscape layout; это не финальная мобильная компоновка.
- Современная Android back/predictive-back интеграция и привязка redial к Activity/process lifecycle. Legacy back callback и ss14 intent-приёмник добавлены, испытаний на устройстве нет.
- Обновление APK с системной установкой и проверкой signing key; исходный desktop version-check не заменяет это.
- SkiaSharp 2.88.9 из Avalonia 11.3: Android native lib имеет 4-КБ ELF alignment. Для устройств с 16-КБ страницами нужна совместимая native сборка или проверенный переход framework. XA0141 не скрыт. Готовность на Android 16/16-КБ устройствах не заявляется.

Порт ещё не является полноценным готовым игровым клиентом. Наличие всех исходных функций не означает, что платформенные зависимости уже перенесены и проверены.

Последняя проверка этой итерации: 22 проверки исходного launcher/UI/данных прошли; отдельно собрались Android APK и desktop-вариант исходного лаунчера. Подпись APK проверена apksigner. В APK проверены исходная SS14.Launcher.dll, отсутствие Launcher.Core.dll и MonoPosix desktop helper; libsodium.so байт-в-байт совпадает с Android NDK-сборкой. 14 выбранных файлов главного содержимого/вкладок/логина совпадают с upstream.
