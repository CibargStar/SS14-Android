# Мобильный интерфейс игры

Галочка **«Мобильный интерфейс игры»** в лаунчере включена по умолчанию. При следующем запуске игры она заменяет компоновку распознаваемых серверных виджетов. Выключение возвращает исходный UI; стик и кнопка **UI** доступны независимо от галочки.

## Управление

Чат закреплён вплотную к правому верхнему углу. Доступны три режима:

| Режим | Отображение |
| --- | --- |
| Скрытый | Только кнопка возврата в углу |
| Минимальный | Короткая история и строка ввода |
| Полный | Увеличенная история и строка ввода |

Кнопка раскрытия находится слева, скрытия — справа. Иконка облачка скрывает чат и возвращает его в последний видимый режим с сохранением черновика. Иконка разворачивания переключает минимальный и полный режимы. История прокручивается одним пальцем; свайп не активирует ссылки, обычное касание срабатывает при отпускании. Каналы, фильтры и отправка используют штатные обработчики сервера.

Стрелка верхнего меню сворачивает и разворачивает исходные кнопки. Иконки центрированы с сохранением пропорций, подписи клавиш скрыты. Кнопки переключения чата/меню действуют при касании, без hover-подсказок. Накладное управление содержит только стик и **UI** для масштаба, скрытия стика и Debug.

## Лобби и руководство

- Лобби использует исходные панели сервера: на широком экране они расположены рядом, на узком доступны кнопки «Лобби» и «Сервер».
- Действия сервера собраны в сетку; панели прокручиваются независимо. Список персонажей и редактор открываются отдельными вкладками. Исходные поля, роли, снаряжение и обработчики сохранены.
- Руководство занимает доступную область с небольшим отступом. «Разделы» переключает оглавление; на узком экране оно открывается отдельно от статьи. История, поиск и ссылки остаются серверными.
- Стик скрывается в лобби, кнопка UI остаётся. Игровые окна и popup перекрывают сенсорное управление и получают свои касания.
- Галочка в лаунчере отключает адаптацию всех перечисленных экранов при следующем запуске игры.

## Устройство адаптера

`MobileServerUiAdapter` в RobustToolbox работает с загруженными виджетами, не меняя Content DLL:

- Исходный `ChatBox` помещается в мобильную рамку внутри `UIScreen`. Регистрация обновляется через `RemoveWidget` / `AddWidgetDirect`.
- Сохраняются widget lookup и цепочка `ChatWindowPanel → ChatBox`: ссылки на персонажей находят `IEntityLinkClickHandler` среди родителей.
- Меню использует исходные `MenuButton`, текстуры и callbacks.
- При отключении или выгрузке экрана восстанавливаются родители, размеры, отступы и подписи.

Контракт: `ChatBox` / `ChatWindowPanel` с исходными вводом, каналами и фильтрами; `GameTopMenuBar` / `MenuButton`. Namespace форка не закреплён. Полностью переписанные виджеты требуют отдельного адаптера. Для лобби распознаются `LobbyGui` / `LeftSide` / `RightSide`, для редактора — `CharacterSetupGui` / `CharEditor`, для руководства — `GuidebookWindow` / `TreeBox` / `SplitContainer`. При отключении возвращаются исходные родители, порядок, размеры и стили. Инвентарь, КПК и прочие окна эта настройка не перестраивает.
