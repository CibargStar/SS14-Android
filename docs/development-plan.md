# Последующие этапы полного порта

Цель остаётся прежней: оригинальный SS14.Launcher и клиент без урезания игровых возможностей, произвольные серверы, независимые обновления APK/движка/контента.

Пользователь подтвердил путь хаб → загрузка контента → игра на Samsung S25 Ultra. Полный раунд, все действия и все форки этим ещё не проверены. По последнему указанию остальные UI и кнопки пока не меняются; разрешено улучшение только стика ходьбы.

Ближайший промежуточный выпуск 0.5.0:

- Стик: один владеющий палец, устойчивые восемь направлений, мёртвая зона без дрожания, отпускание движения при отмене/потере фокуса. Без изменения остальной раскладки.
- Расширение каталога с 7 до 16 точных версий; сохранение официальных repair redirect без загрузки отозванных бинарников.
- Подписанные неизменяемые engine-пакеты, регенерированный экспериментальный delta 294.0.0, APK с тем же сертификатом и новой версией. Перед обновлением каналов сверяются опубликованные SHA-256 и размеры.

Далее:

1. Исправить зависимость ImageSharp с GHSA-v76p-62qx-wwq2, сохранив доступные форматы и лицензионные требования. Продолжить оставшиеся 14 версий из обследования: есть различия платформенного API и переход с SDL2 на SDL3; ошибки audit не скрывать.
2. Проверить реальные входы, игровые действия и длительные раунды на независимых форках, смену движков и повторный запуск процесса. Отделять результаты компиляции от результатов игры.
3. Проверить обновление APK на телефоне с сохранением аккаунта и настроек; обрывы и восстановление engine/content загрузок, потерю сети и reconnect.
4. Перенести оставшиеся native/platform функции: MIDI, веб-контент, системные файлы; довести IME и жизненный цикл, 16-КБ native alignment. Они остаются требованиями полного порта.
5. После согласования общей схемы управления вернуться к остальным сенсорным действиям. Провести проверки на Adreno/Mali, телефоне/планшете, с внешней клавиатурой и мышью; измерить память, нагрев и время кадра.

Промежуточные релизы публикуются в GitHub Releases с точным перечнем изменений и ограничений. Поддержка будущего неизвестного форка не обещается подменой номера движка; нужны соответствующий Android backend и проверка его требований.
