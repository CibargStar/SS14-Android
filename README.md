# SS14 Android — каталог обновлений

Эта ветка хранит машиночитаемый каталог подписанных Android-сборок движка.
Исходники порта находятся в ветке main. Каталог пока пуст: встроенный движок
294.0.1 устанавливается из APK, сетевые сборки ещё не опубликованы.

Записи добавляются после сборки и проверки соответствующей версии исходников.
Каждая платформа android-arm64/android-x64 содержит HTTPS URL, SHA-256 и
Ed25519-подпись пакета. Приватные ключи здесь не хранятся. APK содержит
закреплённый открытый ключ, которым проверяет загружаемый движок.

Манифест обновлений APK появится после публикации проверенной альфа-версии.
Это инфраструктура обновлений, а не готовая тестовая сборка игры.
