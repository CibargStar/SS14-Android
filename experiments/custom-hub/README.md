# Superseded experiment

This was a newly written hub UI over the official API. It did not satisfy the user's requirement to port the original launcher. It is retained here only as a historical experiment; `src/SS14.Android` no longer references or compiles it. The active Android application references the official launcher submodule plus the Android platform patch.

The 0.1.0-dev APK previously uploaded to Drive contains this experimental UI. It must not be described as the original launcher port. The original-launcher development build is 0.2.0-dev and remains incomplete as a full game port.
