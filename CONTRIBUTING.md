# Участие в разработке

## Сообщить об ошибке

Используйте [шаблон issue](https://github.com/CibargStar/SS14-Android/issues/new/choose). Укажите версию APK, устройство и Android, сервер и движок, шаги, ожидаемый результат и лог. Проверьте ошибку на актуальном релизе; удалите токены и личные данные из вложений.

## Внести изменение

1. Подготовьте окружение по [инструкции сборки](docs/building.md).
2. Меняйте Android-host в `src/SS14.Android` или upstream-код в соответствующем submodule.
3. Изменения submodule экспортируйте в **патч**, сохранив указатель на официальный commit. Для новых файлов выполните `git add -N -- path/to/file` перед `git diff --binary`.
4. Проверьте патч на чистом upstream и повторный запуск `scripts/prepare-*.sh`. Общие исправления перенесите в поддерживаемые version-family patches.
5. Запустите относящиеся к изменению [проверки](docs/testing.md). Для ввода и рендера нужен стенд с исходным клиентом.
6. В PR опишите проблему, итоговое поведение, проверки и ограничения.

В проекте сохраняются оригинальные лаунчер, API и протокол каждой версии, проверка подписей, IL-verifier, sandbox и серверные FOV/light-настройки. Сборку версии и проверку игры на сервере указывайте раздельно.

## Содержимое репозитория

В `main` хранятся исходники, патчи, скрипты, тесты, workflows, документация и публичные ключи. Бинарники публикуются в Releases, каталоги — в ветке `updates`. Build output, скачанный контент и приватные ключи в Git не добавляются. Лицензии и атрибуция зависимостей сохраняются.
